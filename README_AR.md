# شاهد IPTV — Android TV

مشروع بداية لتطبيق Android TV بتصميم أسود وأحمر.

## المزايا الحالية
- شاشة دخول بكلمة مرور `1470`.
- واجهة رئيسية للقنوات والأفلام والمسلسلات.
- إدخال رابط قائمة M3U عبر HTTPS.
- مشغل فيديو مبني على AndroidX Media3 / ExoPlayer.
- دعم أزرار التحكم والتركيز الأساسي في Android TV.

## البناء
1. افتح المجلد في Android Studio حديث.
2. اترك Gradle يزامن الاعتماديات.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ثبّت APK على جهاز Android TV للاختبار.

## ملاحظات مهمة
- هذا مشروع مصدر أولي وليس APK موقعاً وجاهزاً للنشر.
- الرابط المحفوظ حالياً في الذاكرة أثناء تشغيل التطبيق فقط؛ أضف تخزيناً آمناً دائماً قبل الإصدار.
- تحليل M3U هنا أساسي ويحتاج تطويراً للتصنيفات والبيانات الوصفية وEPG والترجمات.
- أضف فقط روابط بث تملكها أو لديك ترخيص صريح لتوزيعها. لا يتضمن المشروع قنوات أو أفلاماً مقرصنة.
- كلمة المرور الثابتة 1470 مناسبة كنموذج أولي فقط؛ غيّرها إلى مصادقة آمنة قبل النشر العام.
