# شاهد IPTV — Android TV

مشروع بداية لتطبيق Android TV بتصميم أسود وأحمر.

## المزايا الحالية
- شاشة دخول بكلمة مرور `1470`.
- واجهة رئيسية للقنوات والأفلام والمسلسلات.
- إدخال رابط قائمة M3U الافتراضي من GitHub عبر HTTPS، مع إمكانية تغييره من الإعدادات.
- مشغل فيديو AndroidX Media3 / ExoPlayer مع تفعيل FFmpeg Audio Decoder عبر امتداد Jellyfin.
- دعم أزرار التحكم والتركيز الأساسي في Android TV.

## البناء
1. افتح المجلد في Android Studio حديث.
2. اترك Gradle يزامن الاعتماديات.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ثبّت APK على جهاز Android TV للاختبار.

## المشغل والصيغ
- تم تفعيل امتداد FFmpeg للصوت عبر `org.jellyfin.media3:media3-ffmpeg-decoder:1.6.1+2` مع Media3 `1.6.1`.
- أضيفت وحدتا HLS وDASH لتحسين دعم بث M3U8 وMPEG-DASH.
- امتداد FFmpeg هنا يفك ترميزات صوتية إضافية؛ لا يعني دعم كل صيغ الفيديو أو كل الترميزات على كل جهاز. دعم الفيديو يعتمد أيضاً على مفككات Android والجهاز نفسه.
- قد يتطلب التشغيل الأول اتصالاً بالإنترنت لتنزيل الاعتماديات من Maven Central وGoogle Maven.
- راجع تراخيص امتداد FFmpeg ومكتباته قبل النشر التجاري؛ امتداد Jellyfin المنشور يحمل ترخيص GPL-3.0.

## ملاحظات مهمة
- هذا مشروع مصدر أولي وليس APK موقعاً وجاهزاً للنشر.
- رابط القائمة الافتراضي مضبوط على ملف ara.m3u في مستودع GitHub الذي زودتني به. تغيير الرابط من داخل التطبيق مؤقت أثناء الجلسة في هذه النسخة.
- تحليل M3U هنا أساسي ويحتاج تطويراً للتصنيفات والبيانات الوصفية وEPG والترجمات.
- أضف فقط روابط بث تملكها أو لديك ترخيص صريح لتوزيعها. لا يتضمن المشروع قنوات أو أفلاماً مقرصنة.
- كلمة المرور الثابتة 1470 مناسبة كنموذج أولي فقط؛ غيّرها إلى مصادقة آمنة قبل النشر العام.
