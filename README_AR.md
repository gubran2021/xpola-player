# xPola Player — مشروع Android

## المواصفات
- تطبيق Android فقط.
- شاشة دخول بكلمة المرور `1470`.
- قراءة قائمة M3U مباشرة من الرابط المحدد.
- لا يحفظ ملف القائمة أو الفيديوهات أو بياناتها في التخزين المحلي.
- تشغيل البث باستخدام AndroidX Media3 ExoPlayer.

## بناء APK
1. افتح مجلد المشروع في Android Studio (إصدار حديث).
2. انتظر اكتمال Gradle Sync.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ستجد الملف عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات
- هذا مشروع مصدر قابل للبناء، وليس ملف APK مُجمّعاً.
- كلمة المرور موجودة داخل التطبيق؛ لذلك هي قفل واجهة بسيط وليست حماية قوية.
- التطبيق لا يخزن قائمة التشغيل أو الوسائط عمداً. قد يحتفظ نظام التشغيل أو مشغل الشبكة بمخازن مؤقتة داخلية قصيرة الأجل.
- يجب أن يكون لديك حق الوصول إلى محتوى البث الذي تستخدمه.


## إنشاء APK بدون Android Studio (عبر GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه جميع ملفات هذا المشروع.
2. تأكد أن اسم الفرع هو `main`.
3. افتح تبويب Actions في المستودع واسمح بتشغيل GitHub Actions إذا طُلب ذلك.
4. سيبدأ البناء تلقائياً عند رفع الملفات، أو اختر سير العمل `Build Android APK` ثم `Run workflow`.
5. بعد نجاح المهمة، افتح نتيجة التشغيل ونزّل Artifact باسم `xPolaPlayer-debug-apk`.
6. فك ضغط ملف Artifact وستجد `app-debug.apk` جاهزاً للتثبيت.

ملاحظة: البناء السحابي يحتاج حساب GitHub واتصال إنترنت. هذا المسار لا يتطلب تثبيت Android Studio على جهازك. قد يتطلب أول إعداد للمستودع رفع الملفات إلى GitHub.
